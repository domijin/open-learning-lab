# Study 001 — Learn Marin

## Why Marin?

Marin is both the learning domain and methodological inspiration: an active open-development project whose hypotheses, experiments, failures, and evolving implementation can be inspected rather than consumed as a static course.

This makes it useful for testing an **active curriculum** that must retrieve new project context over time.

## Learning objective

The learner should be able to:

1. independently explain why an open-development research system might exist;
2. reconstruct key design judgments from constraints rather than memorize Marin terminology;
3. distinguish evidence, hypothesis, experiment, finding, and decision;
4. critique Marin's approach and its assumptions;
5. transfer the principles to a new research or learning system;
6. stay current as Marin evolves.
