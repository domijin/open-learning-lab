# Protocol — Retrieval Test

A retrieval test should:

- occur without showing the original answer;
- target reconstruction, not recognition;
- avoid Marin-specific vocabulary when testing underlying mechanism;
- record learner confidence when useful;
- distinguish hints from unaided success;
- record enough context to interpret failure.

Preferred progression:

`immediate recall -> delayed reconstruction -> unseen variant -> far transfer`

Scheduling is currently experimental; H002 is proposed, not assumed true.
