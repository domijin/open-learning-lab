# Glossary

**Learning policy** — Rule that maps learner state, goal, domain, and evidence to the next learning action.

**Hypothesis** — Falsifiable claim about learning or the system.

**Experiment** — Deliberate intervention/evaluation designed to update a hypothesis.

**Observation** — What happened, separated from interpretation.

**Evidence** — Observation or measurement linked to a claim with provenance.

**Finding** — Current synthesis of evidence for a claim, including uncertainty and boundaries.

**Decision** — Action taken because of current evidence.

**Retrieval** — Reconstructing knowledge/capability without the original scaffolding.

**Transfer** — Applying learned structure to a new problem.

**Calibration** — Alignment between confidence and actual performance.

**Expert judgment** — Attributed, contextual human assessment treated as evidence rather than authority.

**Supersession** — Adding a new record that replaces the current interpretation without erasing historical records.
