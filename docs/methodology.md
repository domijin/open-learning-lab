# Methodology

## Core loop

**Hypothesize -> Learn -> Retrieve -> Transfer -> Measure -> Adapt**

### 1. Hypothesize
State a falsifiable pedagogical claim before confirmatory evaluation.

### 2. Learn
Apply a defined intervention: explanation, judgment-first case, visualization, retrieval prompt, expert challenge, etc.

### 3. Retrieve
Remove scaffolding and ask the learner to reconstruct the target capability.

### 4. Transfer
Give a materially new case. Prefer problems where surface vocabulary differs from training.

### 5. Measure
Record outcome, learner effort/time when available, confidence/calibration, and uncertainty.

### 6. Adapt
Update the learning policy or formulate the next hypothesis.

## Evaluation ladder

| Level | Evidence | Example |
|---|---|---|
| L0 | Session performance | "That makes sense." |
| L1 | Immediate retrieval | Explain without looking. |
| L2 | Delayed reconstruction | Re-derive the reasoning later. |
| L3 | Near transfer | Solve an unseen variant. |
| L4 | Far transfer | Apply the principle in a different domain. |
| L5 | Real-world capability | Produce useful work or make a better decision. |

Higher levels dominate lower levels when the learning objective permits them.

## Learning efficiency

The target is not a single benchmark. Conceptually:

`learning value = durable capability x transferability, conditioned on learner effort/time`

Calibration is a critical diagnostic: confidently wrong beliefs deserve targeted intervention.

## Exploration and confirmation

Exploration may inspect results, generate patterns, and change direction. Confirmation should use new evidence and a previously stated claim/evaluation rule.

A confidence interval or statistical test does not repair post-hoc hypothesis selection.

## N-of-1 first

The initial phase optimizes a single learner longitudinally. Later replications discover heterogeneity and boundary conditions. We do not infer population effects from one learner.

## Active learning domains

For active projects such as Marin, the curriculum is not static. The research agent should periodically retrieve current primary sources and record dated provenance. Changes in the domain may create new learning goals or invalidate prior material.

## Expert judgment

Use expert time where value of information is high: critique a foundational assumption, adjudicate competing explanations, identify blind spots, or assess genuine transfer.

Expert judgment is evidence. Its usefulness can later be calibrated by domain and decision type.
