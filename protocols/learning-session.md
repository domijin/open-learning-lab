# Protocol — Learning Session

1. State the capability goal.
2. Cold-check the current learner model.
3. Choose one active hypothesis/intervention.
4. Prefer a problem or decision before explanation when H001 applies.
5. Make learner reasoning observable.
6. Give the minimum scaffold needed to continue productively.
7. Introduce adversarial evidence/constraints.
8. Retrieve current external sources when the domain is active.
9. Record selected observations, not raw transcript by default.
10. End with a future evaluation target; do not call the intervention successful from in-session fluency.
